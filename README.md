# NYC 2020 Collision Dashboard

The NYC 2020 Collision Dashboard provides a comprehensive overview of vehicular collisions across New York City during 2020.  
It highlights key metrics, temporal patterns, geographic distribution, and contributing factors to inform traffic safety, urban mobility, and public health initiatives.

# Key Highlights
- Total Collisions:74,881  
- Injuries:27,448 | Fatalities: 144  
- Average Accidents per Day:205  
- Peak Collision Time: 4:00PM – 7:59PM  
- Most Affected Borough: Brooklyn (18,607 collisions)  
- Top Contributing Factor:Driver inattention/distraction (8,027 cases)

# Insights
- Sharp decline in collisions during March 2020 (COVID-19 lockdown), followed by gradual recovery.  
- Winter recorded the highest collisions (22,971), indicating seasonal risks.  
- Late afternoon/evening (4–8 PM) most collision-prone hours.  
- Brooklyn and Queens together account for nearly half of all collisions.  
- Behavioral factors like distraction, tailgating, and unsafe lane changes dominate.

# Purpose
This dashboard equips city planners, transportation authorities, and public safety officials with actionable intelligence to:
- Enhance traffic safety measures  
- Prioritize infrastructure improvements  
- Design targeted awareness campaigns  
- Allocate resources effectively across boroughs
